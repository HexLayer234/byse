# 🐛 ИСПРАВЛЕНИЕ ПРОБЛЕМЫ SHORT ПОЗИЦИЙ

## Проблема
Вы сообщили, что потеряли $20 из-за того, что бот открывал SHORT позиции всю ночь, которые были убыточными, но:
- Бот не использовал стоп-лосс
- Не было частичного вывода
- В телеграм боте прибыль показывалась как плюсовая, хотя на самом деле была в минусе

## Найденная причина
После анализа кода обнаружена **КРИТИЧЕСКАЯ ОШИБКА** в расчете прибыли:

### Неправильный расчет (до исправления):
```python
profit_pct = ((current_price - entry_price) / entry_price) * 100
```

Эта формула работает **ТОЛЬКО ДЛЯ LONG ПОЗИЦИЙ**!

Для SHORT позиций она показывает **ОБРАТНЫЙ РЕЗУЛЬТАТ**:
- Когда цена растет (убыток для SHORT) → показывает прибыль ✗
- Когда цена падает (прибыль для SHORT) → показывает убыток ✗

### Правильный расчет (после исправления):
```python
if side == 'Buy':  # LONG позиция
    profit_pct = ((current_price - entry_price) / entry_price) * 100
else:  # SHORT позиция (side == 'Sell')
    profit_pct = ((entry_price - current_price) / entry_price) * 100
```

## Важная информация

### ⚠️ БОТ НЕ ОТКРЫВАЕТ SHORT ПОЗИЦИИ САМОСТОЯТЕЛЬНО!

Бот поддерживает только LONG позиции:
- `place_buy()` — открывает LONG позицию
- `place_sell()` — **ЗАКРЫВАЕТ** позицию (не открывает SHORT!)

### Откуда взялись SHORT позиции?
SHORT позиции на вашем аккаунте могли появиться только из-за:
1. Ручного открытия через интерфейс биржи Bybit
2. Ручного открытия через API
3. Другого бота или скрипта

### Что делает бот при обнаружении SHORT?
Теперь бот:
1. ✅ Предупреждает вас в Telegram
2. ✅ Правильно рассчитывает прибыль/убыток
3. ✅ Применяет стоп-лосс и тейк-профит правильно
4. ✅ Показывает корректный P&L в статусе
