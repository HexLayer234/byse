# 📚 ИНСТРУКЦИЯ: Создание нового репозитория с VPS

## Шаг 1: Скопируйте скрипт на VPS

На вашем **ЛОКАЛЬНОМ** компьютере создайте файл `create_new_repo.sh` с содержимым скрипта (см. ниже).

Затем скопируйте на VPS:

```bash
scp create_new_repo.sh root@vm-mini:/root/
```

ИЛИ просто создайте файл прямо на VPS:

```bash
ssh root@vm-mini
cd /root
nano create_new_repo.sh
# Вставьте содержимое скрипта
# Ctrl+X, Y, Enter для сохранения
```

## Шаг 2: Дайте права на выполнение

```bash
chmod +x /root/create_new_repo.sh
```

## Шаг 3: Запустите скрипт

```bash
cd /root
./create_new_repo.sh
```

Скрипт автоматически:
- ✅ Создаст новую директорию `/root/byse-new-repo`
- ✅ Скопирует все `.py` файлы из `/root/byse_bot`
- ✅ Создаст правильный `.gitignore`
- ✅ Создаст `README.md` (если его нет)
- ✅ Инициализирует git репозиторий
- ✅ Создаст ветку `claude/analyze-commit-03dc471-114A2`
- ✅ Сделает initial commit

## Шаг 4: Создайте репозиторий на GitHub

1. Зайдите на https://github.com
2. Нажмите **New repository**
3. Введите название: `byse` или `byse-trading-bot`
4. **НЕ** добавляйте README, .gitignore, лицензию
5. Нажмите **Create repository**

## Шаг 5: Подключите remote и запушьте код

После создания репозитория на GitHub, выполните на VPS:

```bash
cd /root/byse-new-repo

# Добавьте remote (замените URL на ваш!)
git remote add origin https://github.com/ВАШ_USERNAME/byse.git

# Запушьте код
git push -u origin claude/analyze-commit-03dc471-114A2
```

## Шаг 6: Проверьте результат

Откройте GitHub и убедитесь что:
- ✅ Все файлы загружены
- ✅ `config.py` НЕ загружен (защищен .gitignore)
- ✅ Ветка `claude/analyze-commit-03dc471-114A2` создана

## 🔧 Альтернативный способ (вручную)

Если скрипт не работает, можно сделать вручную:

```bash
# 1. Создайте новую директорию
mkdir /root/byse-new-repo
cd /root/byse-new-repo

# 2. Скопируйте Python файлы
cp /root/byse_bot/*.py .
cp /root/byse_bot/*.md . 2>/dev/null || true
cp /root/byse_bot/requirements.txt . 2>/dev/null || true
cp /root/byse_bot/docker-compose.yml . 2>/dev/null || true

# 3. Создайте .gitignore (см. содержимое ниже)
nano .gitignore
# Вставьте содержимое из секции ".gitignore" ниже

# 4. Инициализируйте git
git init
git checkout -b claude/analyze-commit-03dc471-114A2
git add .
git commit -m "Initial commit: BYSE Trading Bot from VPS"

# 5. Добавьте remote и запушьте
git remote add origin https://github.com/ВАШ_USERNAME/byse.git
git push -u origin claude/analyze-commit-03dc471-114A2
```

## ⚠️ ВАЖНЫЕ ПРОВЕРКИ

Перед пушем в GitHub убедитесь:

1. **config.py исключен из git:**
   ```bash
   cd /root/byse-new-repo
   git status
   # config.py НЕ должен быть в списке!
   ```

2. **API ключи не в коде:**
   ```bash
   grep -r "API_KEY\|API_SECRET\|TELEGRAM_TOKEN" *.py
   # Должны быть только в config_example.py как примеры!
   ```

3. **Проверьте config_example.py:**
   - Убедитесь что там НЕТ реальных ключей
   - Только заглушки типа "YOUR_API_KEY_HERE"

## 🆘 Помощь

Если что-то не работает:

1. Проверьте права доступа: `ls -la /root/byse_bot`
2. Проверьте что вы в правильной директории: `pwd`
3. Посмотрите ошибки скрипта внимательно
4. Убедитесь что git установлен: `git --version`
